Tsetlin Pair Lab
Vanilla Tsetlin Machine · 20 Newsgroups · validation data

Can a team of simple rules tell if two posts are about the same thing?

The task

Take two posts from a news group. Are they from the same category, or from different ones? The machine never sees category names. It only sees which words appear.

The machine

A team of rules. Each rule is a checklist of word conditions. A rule fires only if every condition is true. Fired rules vote, and the bigger side wins. (The report says clause. Same thing.)

The learning

Every condition is controlled by a tiny learner that gets a reward or a penalty after each training example. Slowly it decides if the condition belongs in the rule.

    Watch a tiny machine learn

    Hidden rule: “same” only if both space and orbit are present. The other four words are noise. Press Train. A gauge above the dashed line means “this condition is in the rule”.

    On a small screen, swipe the gauges sideways.

    TYPE I solid border: the rule is helped to fire on matching examples.
    TYPE II dashed border: the rule fired wrongly, so it gets a condition that blocks it.

    This lab uses the classic textbook layout: 8 rules, half voting “same” and half “different”, 30 steps on each side. The project's model (BitTM) groups rules per class and uses 100 steps, but the learning rules are the same.

    What the experiments found

    All numbers: 4,000 validation pairs, mean of 3 random seeds. The test set has not been used.

    Changing how the pair is written down helped most (+4 points).

    Dashed line: chance (0.50). Amber line: the word-overlap baseline (0.605). Black whisker: spread over seeds.

    A smaller T helped a little, then it gets noisy.

    Run it yourself

    This page is one self-contained file. Serve it from your own computer. Only the fonts need the internet.

    .\.venv\Scripts\python.exe serve_dashboard.py

    Then open http://127.0.0.1:8060. Run the command from the tsetline-project folder. After you change the data or the template, add --rebuild.

    Everything above is measured by the code in the project folder. Validation only: the test split is untouched. Settings were picked on validation, so the scores are slightly optimistic. Sample pairs show only the first 300 characters of each post, with email addresses removed. The model read the whole post.
